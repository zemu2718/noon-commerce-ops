# 04 noon 前台商品与竞品检查

从买家视角检查商品展示、比较竞品，排查影响下单和退货的问题。

[noon 买家官网](https://www.noon.com/)

## 按场景开始

| 要做什么 | 先看 |
|---|---|
| 选品、比较竞争对手 | [选品与竞品比较](#compare) |
| 商品刚上架或修改过资料 | [上架后检查](#listing-check) |
| 销量下降、怀疑前台有问题 | [销量下降排查](#sales-check) |
| 参加促销或发优惠券 | [活动展示检查](#promotion-check) |
| 保存检查结果、交给同事跟进 | [记录问题与跟进](#record) |

每次先完成 [检查前准备](#prepare)，再选对应场景。

<a id="prepare"></a>

## 1. 检查前准备

- 先选择经营国家、语言和配送地区；比较时保持条件一致，并记录查看时间、登录状态及会员或专属优惠。
- 比较同款或可替代商品，核对品牌、型号、尺寸、容量、数量、配件和保修。
- 区分商品评价与卖家评价，确认当前展示的是哪个卖家的报价。
- 记录商品链接和所选规格。切换颜色、型号或数量后，重新检查价格、卖家和配送。

不同地址、账户和规格可能看到不同结果。记录这次实际看到的内容，不把一次展示当作所有买家都看到的情况。页面未显示的信息写“未显示”。

本指南只检查页面，不提交订单、不付款、不联系卖家或发布评价。需要登录或进一步操作时另行授权；后台改价和上架仍按公司审批执行。截图先遮去地址、姓名和账户信息。

<a id="compare"></a>

## 2. 选品与竞品比较

| 看哪里 | 记录什么 | 用来决定什么 |
|---|---|---|
| 搜索结果 | 买家可能用的关键词、结果中的商品、可见广告标识 | 商品定位是否合适，哪些词需要进一步研究 |
| 价格与配置 | 同规格价格带、数量、配件和保修差异 | 我们有什么差异，按实际成本算后是否还有利润 |
| 主图和标题 | 第一张图能否看懂，标题是否突出型号和用途 | 我们需要把哪些卖点讲清楚 |
| 评价与问题 | 买家反复提到的优点、缺点、尺寸和质量问题 | 选品、采购、包装或说明能否解决这些问题 |
| 配送与售后展示 | 到货日期、配送费用、退货和保修信息（如有） | 买家为什么可能选择另一家 |

评论量、星级、搜索位置和缺货状态都不能直接换算成竞品销量或利润。搜索词热度与真实转化需要结合可获取的后台数据验证。

<a id="listing-check"></a>

## 3. 上架后检查

- [ ] 商品链接能打开，目标配送地区能购买。
- [ ] 当前卖家正确，默认购买报价是否是我们的；如有其他卖家报价入口，一并检查。
- [ ] 标题、图片、参数与实物一致，英文和阿拉伯文没有明显歧义。
- [ ] 颜色、尺寸、型号、件数和配件清楚，切换规格后信息对应正确。
- [ ] 价格、优惠、配送费用和使用条件显示清楚，没有把限条件优惠当成人人可得的价格。
- [ ] 到货承诺、退货和保修信息与实际服务相符（以页面可见内容为准）。

发现内容问题先保存链接、时间和截图，再交负责同事修改。属性和图片要求查 [商品上架](02-noon卖家帮助中心.md#listing)，购买框问题查 [价格与库存](02-noon卖家帮助中心.md#pricing)。

<a id="sales-check"></a>

## 4. 销量下降排查

| 看到的情况 | 下一步核实 | 不要直接做什么 |
|---|---|---|
| 商品打不开或无法购买 | 后台上架状态、可售库存、配送范围 | 还没解决可售问题就加广告预算 |
| 当前购买报价不是我们 | 报价、Buy Box（购买框）和适用的卖家表现规则 | 只为抢购买框降到利润底线以下 |
| 竞品看起来更便宜 | 是否同规格、同数量，优惠是否有门槛，配送费是否另算 | 只看页面大字价格就跟价 |
| 我们到货更慢 | 配送地区、库存位置、入仓和履约处理情况 | 仅凭一次到货预估认定原因 |
| 商品信息不清楚、负面反馈集中 | 对照后台转化和退货数据，检查实物、包装及描述 | 未验证就认定改图一定能提升销量 |

前台观察用来提出排查方向，结论还要结合销售、库存、广告及售后报表。发货问题查 [FBN](02-noon卖家帮助中心.md#fbn)／[FBP](02-noon卖家帮助中心.md#fbp)，评价问题查 [信誉管理](02-noon卖家帮助中心.md#reputation)，投放表现查 [广告指标与报表](03-noon广告帮助中心.md#reports)。

<a id="promotion-check"></a>

## 5. 活动展示检查

检查活动标识、优惠券条件、最低消费、限定支付方式、有效期及配送费用。区分页面售价、满足条件后的价格和最终结算价；没有看到结算页面时，不填写“已验证到手价”。

把实际优惠方案交财务或运营核算，计入卖家承担的折扣、平台费用、广告和预期售后成本。活动后结合销量与贡献利润复盘，不能只看订单增加。

| 主图、标题和主要卖点 | — | — | — |
| 可购买状态、当前购买报价的卖家 | — | — | — |
| 到货承诺 | — | — | — |
| 买家反复提到的问题 | — | — | — |

单品检查时，竞品列留空；多个竞品分别记录，避免把不同商品的信息混在一起。

- **已确认的问题：** 写观察事实，附截图或数据。
- **还需核实什么：** 可能原因、需要的后台数据。
- **下一步：** 谁处理、做什么、什么时候复查。
