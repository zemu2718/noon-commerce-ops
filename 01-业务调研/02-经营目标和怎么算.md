# 02 经营目标和怎么算

目标是少花冤枉钱、减少重复工作，并增加有利润的销售。先记录现在的情况，再确定这次想改善什么，不预填增长比例；涉及公司要求的目标再找相关同事确认。

## 选要看的数字

这里保留算法和口径。某次改进的范围、统计时间、币种、报表来源、原值、目标和结果，只填写在该次 [改进记录](../02-岗位流程与改进/04-改进清单.md)，不在这里重复登记。

| 想改善什么 | 可以看什么数字 |
|---|---|
| 多卖且赚钱 | 净销售额、贡献利润额和利润率 |
| 少花钱 | 广告、仓储、履约、退货及返工等可改善费用 |
| 少压货 | 库存成本、仓龄、周转、缺货时长 |
| 提高人效 | 同样工作量下，操作、检查、异常处理和维护的总时间，以及错误次数 |

每次改进选一项主要目标，不必把所有指标都考核一遍；同时写清不能牺牲什么，例如不能为了销量跌破利润底线。

## 数字要按同一种算法比较

| 数字 | 先说清楚 |
|---|---|
| 销量、订单、净销售额 | 件数还是订单数；下单还是完成日期；取消、折扣、退款、税和运费怎么处理 |
| 贡献利润 | 收入减去哪些成本和费用；采购、物流、平台、广告、仓储和退货如何归到商品，避免重复扣算 |
| 广告效果 | 归因窗口、报表延迟、销售额范围；ROAS 是归因销售额÷广告花费，不是利润 |
| 库存覆盖与缺货 | 可售、在途、不可售分开；按什么销量窗口算；新品、零销量和活动如何处理 |
| 退货率 | 按件还是按订单；退货往往晚于销售，要用可比较的订单批次或观察期 |
| 费用与回款 | 用实际结算核对；商品级、包裹级、店铺级费用不能重复计入；估算费用不等于实际扣款 |

用到某项指标时，再补公式、报表字段、时区、更新频率、缺数据怎么办及来源日期。公司算法不清楚时，记下向谁确认的结果。不同币种不直接相加，转换时写明汇率与日期。费用不全时只能说部分利润测算，不能叫净利润。

## 不要把效果算大了

- 前期调研、安装、开发和培训实际花的时间与费用，和日常操作、检查、异常处理、维护及订阅花费分开记。写清比较的是一周、一个月还是其他期间，并按相同工作量比较；不能只看运行后省了多少，也不能把全部前期投入当成每期都会发生的成本。
- 估计多久收回投入时，工时与现金分开算；还没发生的节省只写“预计”，不算已实现收益。
- 省了工时不等于少发了工资；写清省出的时间用来做什么。
- 广告报表里的销售不等于广告新带来的销售。
- 库存占款下降不等于赚了同样多的钱。
- 收回一次错误扣费不等于每月都能省这笔钱。
- 已在利润里体现的费用节省，不再额外加一遍。
- 对比时说明活动、季节、价格、库存和商品数量的变化，不能把所有增长算到工具头上。
