# noon 部门流程与自动化改进

**梳理同事的日常工作和部门流程，整理新人及 Agent 能使用的岗位指南与 SOP，再找适合自动化、降本增效的工作。**

目前尚未实际跟岗、选定试点或运行 Agent。先看完整主流程，边跟岗边整理，不必等所有 SOP 写完才研究改进。

第一次了解业务，先读 [跨境电商从选品到回款](00-业务基础与平台指南/01-跨境电商从选品到回款.md)，认识通用环节、货与订单和资金的流转，以及常见履约模式，再看公司实际怎么做。

## 平时从这三个入口开始

| 我要做什么 | 打开哪里 |
|---|---|
| 看同事怎么工作、记下过程和疑问 | [部门流程与跟岗记录](01-业务调研/03-从选品到回款走一遍.md) |
| 整理或查找岗位指南、具体操作步骤 | [岗位工作清单](02-岗位流程与改进/01-岗位工作清单.md) |
| 记问题，继续调查、试用和看结果 | [改进清单](02-岗位流程与改进/04-改进清单.md) |

跟岗时先记观察；整理时把确认的做法写入 SOP，把改进想法放进改进清单，不重复抄写。一件改进从调查到结果接着写，长了再拆。

新人和 Agent 按“岗位清单 → 实际岗位上手指南 → 当前任务 SOP”使用。模板只在整理资料时看，不是实际岗位指南；读懂 SOP 不等于获准操作后台。

## 需要时再查

- 了解公司：[店铺和团队情况](01-业务调研/01-店铺和团队情况.md)。
- 算成本和收益：[经营目标和怎么算](01-业务调研/02-经营目标和怎么算.md)。
- 找现成工具、比较付费与开源方案：[找工具和做选择](03-方案调研与选型/01-找工具和做选择.md)。
- 准备试用、检查结果与操作权限：[先试一小部分](04-落地实施/01-先试一小部分.md)。
- 查平台：[卖家后台](https://sell.noon.com/) · [卖家帮助](00-业务基础与平台指南/02-noon卖家帮助中心.md) · [广告帮助](00-业务基础与平台指南/03-noon广告帮助中心.md) · [商品与竞品检查](00-业务基础与平台指南/04-noon前台商品与竞品检查.md)。

先用已有功能和工具，确实不够才开发。效果要算上人工检查和维护，不只是把工作转给另一个人。付费、资料外发及改价、采购等操作仍须实际授权；密码、密钥、客户资料和原始敏感报表不放仓库，远程仓库使用前确认设为私有。

方法参考：[Palantir AIP 知识库](https://qcnrt01y72yf.feishu.cn/wiki/Gs4Rw7RiXipXorka2FhcpuPVnNh)。借鉴资料有依据、操作先批准、结果要检查的做法，不要求购买或重建平台。
